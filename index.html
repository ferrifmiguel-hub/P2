  1. Crear la carpeta en nusetro disco duro, trabajamos en local.
  2. Abrimos el programa Visual Studio Code
  3. Arrastramos la carpeta que hemos creado (P1) al explorador o open folder desde el explorador
  4. Creamos el new file: index.html
  5. Editamos el fichero (trabajamos ahi con los codigos que sean)
  6. Entramos al navegador
  7. Entramos a nuestro perfil de GitHub
  8. Crearemos un repositorio p1
  9. Dentro del repositorio: Add file y upload files
  10. Una vez el archivo index.html aparece directorio de nuestro repositorio, vamos a settings, en la barra de la izquierda buscamos pages y en GitHub pages cambiamos de none a main y apretamos save
  11. Después de eso nos aparecera el mensaje azul, actualizamos y nos aparecera nuestra url del repositorio publicado en formato webpage
